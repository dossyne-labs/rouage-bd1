# Suivi d'appels Rouage — BD1

Chaque prospect est une **Issue** de ce depot : https://github.com/dossyne-labs/rouage-bd1/issues

## Mettre a jour un statut
1. Ouvre l'Issue de l'entreprise (depuis la page du tableau de bord, ou directement dans l'onglet **Issues**).
2. Utilise les boutons de statut sur la page du tableau de bord (ca fonctionne sans compte GitHub), ou change le label `statut: ...` directement ici.
3. Ajoute une note si besoin — tout l'historique reste visible dans l'Issue.

## Tableau de bord
La page en ligne (GitHub Pages) lit automatiquement les Issues et affiche la liste, les priorites et les statuts.

## Labels
- `statut: ...` — l'etat de l'appel (a-appeler, tente, barrage, messagerie, injoignable, decideur joint, refus, RDV obtenu, sans suite)
- `priorite: A / B / C` — la priorite d'appel
- `a-requalifier` — une info du dossier est a reverifier avant l'appel
- `sans-numero` — aucun numero de telephone trouve pour l'instant
